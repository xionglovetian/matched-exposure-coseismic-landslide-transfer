## Superseded data

- `metrics/figure_source_data/fig4_exposure_matched_effects_route1_superseded.csv`
  is retained for history only. It used the earlier Route 1 aggregation
  pipeline, whose point estimates differ from the q2_x3 manuscript pipeline. Do
  not use it for Table 3 or Table 6.
- The Route 1 claim matrix predates the co-primary recomputation and still
  quotes the historical tile-level value `+0.0355 [0.0242, 0.0513]` for R1-C1.
  That entry is a frozen record of the earlier decision point, not a
  manuscript number. The manuscript number is the q2_x3 seed-stratified value in
  Table 3.
- `metrics/route1_bootstrap/route1_e1_tile_bootstrap.csv` is a historical
  tile-level bootstrap variant and is not the manuscript headline.
- The two-architecture versions of `q2_x3_seed_stratified_t_interval.csv`,
  `q2_x3_seed_stratified_bootstrap.csv` and `q2_x3_seed_level_macro_effects.csv`
  were replaced in place by their four-backbone supersets. The earlier snapshots
  remain recoverable from the tag `repro-20260929-r6` and from the superseded
  repository `coseismic-landslide-transfer-benchmark`.

## Which interval family is which

Two component-resampling families appear in the package and they are not
interchangeable:

- `metrics/q2_x3_bootstrap/x3_spatial_cluster_bootstrap.csv` and
  `metrics/q2_x3_bootstrap/x3_target_macro_component.csv` resample connected
  components with the three seeds pooled into one estimate. This is the family
  quoted in the component-bootstrap column of Table 3.
- `metrics/q2_x3_seed_stratified_bootstrap/q2_x3_seed_stratified_bootstrap.csv`
  resamples seeds within regions and then components within each selected seed.
  This is the seed-conditioned sensitivity family, and its `component` and
  `merged30` rows are the ones printed in
  `reports/revision_20261015/E3_four_backbone_matched_exposure.md`.

## Reproduction commands

```powershell
# Seed-level effects, seed-stratified t intervals and the seed-conditioned
# component sensitivity. Deterministic: reruns reproduce the committed CSVs.
python scripts/q2_x3_seed_stratified_reanalysis.py `
  --tile-root metrics/q2_x3_tiles `
  --spatial-index data_manifests/target_spatial_index.csv `
  --output-dir metrics/q2_x3_seed_stratified_bootstrap --draws 10000

# Target-macro component interval quoted in Table 3, for all four backbones.
python scripts/q2_x3_target_macro_component_bootstrap.py `
  --tile-root metrics/q2_x3_tiles `
  --spatial-index data_manifests/target_spatial_index.csv `
  --output metrics/q2_x3_bootstrap/x3_target_macro_component.csv --draws 10000
```
