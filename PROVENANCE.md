every relocated object is listed there.

report or a `q2_x3` summary.

  standalone repository is no longer needed for recovery. Everything the
  manuscript cites is in this repository at tag `repro-20261017-r8` or later.

## Which interval family is which

Two component-resampling families appear in the package and they are not
interchangeable:

- `metrics/q2_x3_bootstrap/x3_spatial_cluster_bootstrap.csv` and
  `metrics/q2_x3_bootstrap/x3_target_macro_component.csv` resample connected
  components with the three seeds pooled into one estimate. This is the family
  quoted in the component-bootstrap column of Table 2.
- `metrics/q2_x3_seed_stratified_bootstrap/q2_x3_seed_stratified_bootstrap.csv`
  resamples seeds within regions and then components within each selected seed.
  This is the seed-conditioned sensitivity family, and its `component` and
  `merged30` rows are the ones printed in
  `reports/revision_20261015/E3_four_backbone_matched_exposure.md`.

## Reproduction commands

```powershell
# Seed-level effects, seed-stratified t intervals and the seed-conditioned
# component sensitivity. Deterministic: reruns reproduce the committed CSVs.
python scripts/q2_x3_seed_stratified_reanalysis.py `
  --tile-root metrics/q2_x3_tiles `
  --spatial-index data_manifests/target_spatial_index.csv `
  --output-dir metrics/q2_x3_seed_stratified_bootstrap --draws 10000

# Target-macro component interval quoted in Table 2, for all four backbones.
python scripts/q2_x3_target_macro_component_bootstrap.py `
  --tile-root metrics/q2_x3_tiles `
  --spatial-index data_manifests/target_spatial_index.csv `
  --output metrics/q2_x3_bootstrap/x3_target_macro_component.csv --draws 10000

# Scale experiments (Tables S19 and S20). The absolute paths at the top of each
# script must be pointed at a local project checkout first; see
# metrics/scale_experiments/README.md for the run settings and expected result.
```
